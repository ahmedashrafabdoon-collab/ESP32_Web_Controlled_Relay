# ESP32 Web Server Relay Control 🌐⚡

A simple IoT project that demonstrates how to control a relay module using an ESP32 Web Server.

The project allows users to turn a connected device ON and OFF remotely through a web interface built with HTML, CSS, and JavaScript.

## 🚀 Features

- Control a relay module through a web browser
- ESP32 acts as a web server
- Simple and responsive web interface
- Wireless control using WiFi
- Demonstrates communication between hardware and web technologies

## 🛠️ Technologies Used

### Hardware
- ESP32 Development Board
- Relay Module
- Lamp

### Software
- Arduino IDE
- C++ (Arduino Programming)
- HTML
- CSS
- JavaScript
